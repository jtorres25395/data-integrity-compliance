## Signal Key

| Signal | Meaning | How the Signal Is Determined |
|---|---|---|
| ⚪ **Model / Baseline** | Fixed reference configuration | **January–June 2018** is the fixed analytical model. Every other six-month snapshot is compared directly and independently with this configuration. The model is not treated as a chronological starting point. |
| ⭐ **Strong Success** | Strongly resembles or improves upon the successful model | Family-based placement remains strong while placement-pressure indicators remain controlled or improve. A row does not have to reproduce every 2018 percentage exactly to receive this signal. |
| 🟢 **Success** | Configuration remains consistent with a functioning Relative Foster Home Placement system | Differences from the model exist, but the combined pattern does not show meaningful displacement into unresolved, emergency, congregate-care, or safety-pressure categories. |
| 🟡 **Watch** | Limited deviation from the successful model | One or more important indicators differ materially from the model, but the entire placement configuration does not yet show broad or severe placement pressure. |
| 🟠 **Warning** | Multiple indicators are moving away from the successful configuration | Family-based placement is weaker and/or placement-pressure indicators are meaningfully elevated when compared directly with the 2018 model. |
| 🔴 **High Risk** | Strong placement-system pressure is visible across several proxies | Significant differences appear across multiple important categories, such as declining Family Foster combined with elevated Group Home, No Identified Placement (NIP), Shelter >21 Days, Runaway, or Missing Child. |
| 🚨 **Possible Failure** | The placement configuration substantially differs from the successful model | Family-based placement is substantially weaker while multiple unresolved, congregate-care, emergency-placement, or safety indicators are elevated. This is a **proxy-based program signal**, not proof that an individual placement failed or proof of causation. |
